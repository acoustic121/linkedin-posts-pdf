From developer privacy concerns to massive infrastructure shifts, here are today's biggest tech updates.

🔹 Postman Auto-Installs AI Plugins & Prompts Data Sharing Concerns
 ↳ What happened: Postman rolled out an update that silently installed AI plugins and requested access to share API data by default. Developers discovered the change through a GitHub issue, raising major privacy concerns across engineering teams handling sensitive enterprise APIs.
 ↳ Why it matters: Always audit developer tooling updates to prevent accidental exposure of proprietary corporate API payloads and credentials.
 ↳ Read story: https://github.com/postmanlabs/postman-app-support/issues/14370

🔹 ChatGPT Search Volume Hits 20% of Google's Search Traffic
 ↳ What happened: OpenAI announced that search queries through ChatGPT have reached 20 percent of Google's total search volume. Millions of users are now defaulting to AI conversational responses over traditional web search link lists.
 ↳ Why it matters: Developers and businesses must rethink web discovery strategies as AI conversational engines replace standard search engines.
 ↳ Read story: https://www.theverge.com/ai-artificial-intelligence/1025482/openai-says-chatgpt-is-catching-up-to-google-in-search

🔹 OpenAI Builds Custom Git Backend Called Pando
 ↳ What happened: OpenAI revealed Pando, a custom Git-compatible backend designed to handle the massive repository scale generated by AI tools like Codex. Traditional Git setups struggle with the sheer volume and velocity of AI-written code commits.
 ↳ Why it matters: As AI code generation grows, developer infrastructure and version control tools will require foundational re-engineering.
 ↳ Read story: https://openai.com/index/scaling-git-at-openai
