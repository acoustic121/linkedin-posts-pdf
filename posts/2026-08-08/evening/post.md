🔹 The SSRF Fix Cursor Writes Is Still Vulnerable (CWE-918)
 ↳ What happened: A developer analysis revealed that when AI code editors like Cursor are asked to patch Server-Side Request Forgery vulnerabilities, they often write flawed checks. Node.js can resolve hostnames a second time when opening sockets, cleanly bypassing the AI's initial IP range validations.
 ↳ Why it matters: Automated code generation is a massive productivity booster, but blindly trusting AI security patches can leave critical backdoors wide open.
 ↳ Read story: https://dev.to/c_k_fb750e731394/the-ssrf-fix-cursor-writes-is-still-vulnerable-cwe-918-1e41

🔹 The CPU is back: Rethinking the CPU-GPU split for LLM inference
 ↳ What happened: Red Hat published a deep dive into modern hardware architecture, arguing that heavy reliance on GPUs alone is hitting bottlenecks during large language model inference. The piece explores shifting specific workloads back onto CPUs to optimize processing pipelines and memory efficiency.
 ↳ Why it matters: As inference costs scale, hybrid CPU-GPU architectures will become essential for sustainable cloud infrastructure operations.
 ↳ Read story: https://www.redhat.com/en/blog/cpu-back-rethinking-cpu-gpu-split-llm-inference
